# Portfolio

This repository is a top-level portfolio workspace organized into three independent tracks.

## Repository Structure

```text
portfolio/
├── katech-automotive/
├── korec-rehab/
└── masters-research/
```

## Tracks

- `katech-automotive`: Automotive software, integration assets, and platform-oriented projects.
- `korec-rehab`: Embedded C firmware profile work for rehabilitation engineering use cases.
- `masters-research`: Python-based deep learning and experiment workflows.

## How to Navigate

- Enter automotive track: `cd katech-automotive`
- Enter rehab track: `cd korec-rehab`
- Enter research track: `cd masters-research`

## Notes

- Each track is managed independently.
- Private or non-public components are excluded via `.gitignore` rules.
