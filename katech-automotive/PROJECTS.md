# Projects Overview

## Adaptive AUTOSAR
Platform and integration assets for Adaptive AUTOSAR workflows across target environments.
Focus areas include platform structure alignment, integration layout, and deployment-oriented organization.

## Autonomous Driving Stack
Modular stack for driving functions and control flow integration.
Includes module-oriented design for control, decision, communication, and runtime orchestration.

## Time Synchronization Daemon
Components and integration assets for deterministic time synchronization in embedded networks.
Covers synchronization workflow and timing-service operation across modules.

## TSN Communication Stack
Resources for TSN-based communication structure and validation flow.
Targets deterministic networking and module-level communication integration.
