# Security Policy

## Reporting Vulnerabilities
Please do not disclose security issues in public discussions.
Report vulnerabilities through a private communication channel with:
- Affected component/path
- Reproduction steps
- Impact summary
- Suggested mitigation if available

## Scope
This repository is maintained as a public-facing portfolio structure.
Security handling prioritizes prevention of sensitive data disclosure in tracked paths.

## Repository Security Controls
- Secrets and key materials must not be committed.
- Build outputs, logs, and private implementation paths must remain excluded via `.gitignore`.
- Public documents should describe interfaces and usage flow without exposing confidential implementation details.

## Responsible Disclosure
After receiving a report, remediation should be prepared before public disclosure.
Public communication should occur only after mitigation is available and sensitive details are sanitized.
